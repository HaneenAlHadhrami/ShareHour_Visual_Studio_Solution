# كيف تشغّلين Share Hour وتضيفين صور التقرير

## تشغيل المشروع في Visual Studio 2026
1. فكّي ضغط `Share_Hour_ASPNET_Core_Source.zip`.
2. من Visual Studio اختاري **File > Open > Project/Solution** وافتحي `ShareHour.Web/ShareHour.Web.csproj`.
3. تأكدي أن **.NET 8 SDK** و **ASP.NET and web development** workload مثبّتان.
4. من Solution Explorer اضغطي بزر الفأرة الأيمن على المشروع ثم **Restore NuGet Packages**. تحتاجين اتصال إنترنت للمرة الأولى لتنزيل حزمة EF Core SQLite إذا لم تكن مخزنة محليًا.
5. اختاري **Build > Build Solution**؛ إذا ظهر خطأ انسخي رسالة الخطأ كاملة قبل تغيير الأكواد.
6. اضغطي **Ctrl + F5**، ثم افتحي رابط `https://localhost:...` الذي يظهر.

## بيانات الدخول التجريبية
- المالك Owner: `owner@sharehour.test`
- المستأجر Renter: `renter@sharehour.test`
- كلمة المرور التجريبية للحسابين: `Demo123!`
- هذه حسابات تجريبية فقط، لا تستعملي كلمة المرور في نظام منشور.

## خطوات التصوير
1. افتحي الصفحة الرئيسية وصوري عرض الأدوات (Screenshot 01).
2. سجّلي دخولًا وصوري الواجهة بدون إظهار كلمة المرور (02).
3. ادخلي بحساب المالك وأنشئي أداة جديدة وصوري النتيجة (03).
4. ابدئي حجزًا بحساب المستأجر، اختاري وقتًا مستقبليًا، وصوري التقدير المباشر للتكلفة (04).
5. جربي وقتًا متداخلًا أو تاريخًا سابقًا وصوري رسالة الخطأ (05).
6. احجزي وقتًا صحيحًا وصوري حالة Pending (06).
7. ادخلي بحساب المالك وصوري قائمة Owner Requests وقرار Approve (07).
8. عودي للمستأجر وصوري حالة Approved (08).
9. صوري Solution Explorer بما يظهر ملفات Models وPages وData وServices (09).
10. بعد رفع المستودع Public على GitHub صوري صفحته (10).

## إضافة الصور في Word
- افتحي `Share_Hour_COMP4701_Phase1_Report.docx`.
- اذهبي إلى **Appendix A**؛ توجد مربعات باسم Screenshot 01 إلى Screenshot 10.
- ضعي المؤشر داخل المربع المطلوب، واحذفي النص `[ INSERT REAL SCREENSHOT ]`، ثم **Insert > Pictures > This Device**.
- اختاري الصورة المناسبة، واضبطي عرضها بحيث يبقى داخل الصفحة. إذا تمدد الجدول انتقلي إلى الصورة التالية في صفحة لاحقة.
- غيّري أرقام الاختبارات `NOT RUN` إلى نتائجك الحقيقية فقط. اكتبي نتائج المقابلات الحقيقية وأسماء المشاركين ونسب مساهماتهم الفعلية.
- حدّثي جدول المحتويات من **References > Update Table**، ثم **File > Export > Create PDF/XPS**.

## أمور لا تُرفَع إلى GitHub
`sharehour.db` وملفات bin/ وobj/ وأي كلمات مرور أو ملفات فيها بيانات شخصية.
